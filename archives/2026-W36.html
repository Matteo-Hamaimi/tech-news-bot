LangChain – Plateforme d'ingénierie pour agents IA

LangChain est le cadre de référence pour construire des applications complexes avec des LLM, notamment les agents, les chaînes de prompts, et l'intégration avec des outils externes. C'est l'infrastructure sur laquelle reposent des dizaines de milliers de projets IA. Elle abstrait les complexités d'orchestration entre modèles, mémoire et outils.

Ollama – Exécution locale de modèles LLM
#6af93ea43beb7b95 · GitHub
Ollama permet de télécharger et exécuter des grands modèles de langage (comme DeepSeek, Qwen, Gemma) directement sur sa machine sans serveur distant. C'est une solution pour ceux qui veulent tester ou déployer des LLM tout en conservant les données localement. Le projet supporte une large gamme de modèles et simplifie l'installation technique.
Firecrawl – API pour explorer et scraper le web à grande échelle
#2c7b3111701b0646 · GitHub
Firecrawl est une API permettant de chercher, scraper et interagir avec des contenus web à grande échelle pour alimenter des systèmes IA. Elle résout le problème de l'accès fiable à des données web dynamiques sans coder un scraper maison. C'est un outil clé pour construire des pipelines RAG (Retrieval-Augmented Generation) robustes.
Dify – Plateforme collaborative pour construire des workflows et RAG
#da3220666e74d3ef · GitHub
Dify est un studio visuel permettant de construire des workflows d'agents IA et des pipelines RAG sans code, puis de les déployer on-premise ou en cloud. Elle accélère le passage du prototype à la production en évitant de reconstruire une infrastructure technique complète. L'outil supporte une large gamme de modèles et d'intégrations.
Graphify – Transformer une base de code en graphe de connaissance interrogeable
#dd6a9d14a094d159 · GitHub
Graphify convertit une codebase complète (code, docs, schémas BD, configs, PDFs) en graphe de connaissance structuré et interrogeable, sans utiliser de base vectorielle. Elle permet aux agents IA de comprendre précisément une architecture logicielle et récupérer le contexte technique pertinent. Cela améliore la qualité des interventions d'agents de code comme Claude Code ou Cursor.
Claude Mem – Mémoire persistante pour agents IA cross-sessions
#b8da10635efbda0c · GitHub
Claude Mem capture et compresse tout ce qu'un agent effectue durant une session, puis réinjecte le contexte pertinent dans les sessions futures. Cela permet aux agents de progresser et d'accumuler du savoir sans repartir de zéro à chaque appel. C'est un élément clé pour construire des agents ayant une continuité d'apprentissage.
Headroom – Compression de tokens pour LLM et agents IA
#9a75aafc0f232f11 · GitHub
Headroom compresse les sorties d'outils, logs, fichiers et chunks RAG avant qu'ils ne parviennent au LLM, réduisant jusqu'à 95% du nombre de tokens utilisés (60-95% pour JSON, 20% pour code). Cela diminue coûts et latence sans dégrader la qualité des réponses. L'outil se déploie en bibliothèque, proxy ou serveur MCP.
